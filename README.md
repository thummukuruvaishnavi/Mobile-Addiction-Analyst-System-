# 📱 Mobile Addiction Analyst System

## 📖 Overview

The Mobile Addiction Analyst System is an Android application developed using Kotlin and Jetpack Compose in Android Studio. It helps users monitor smartphone usage, analyze screen time, identify mobile addiction levels, and provide AI-based recommendations to improve digital well-being.

---

## ✨ Features

- 🔐 User Login
- 📊 Dashboard
- 📱 Screen Time Tracking
- 📈 App Usage Analysis
- 🧠 Addiction Risk Analysis
- 🤖 AI Recommendations
- 🔔 Notifications
- 🌙 Dark Mode
- 📜 Usage History
- 👤 User Profile

---

## 🛠 Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio
- Material Design 3
- Navigation Component
- UsageStatsManager
- ViewModel
- State Management

## 🚀 How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle.
4. Run the application on an Android device or emulator.
5. Grant Usage Access permission when prompted.
